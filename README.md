# 🧮 Advanced Scientific Calculator

A modern, responsive **Scientific Calculator** built with **HTML, CSS, and Vanilla JavaScript**. It supports both basic arithmetic and advanced mathematical operations through a clean and user-friendly interface.

---

## ✨ Features

### 🔢 Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Parentheses `()`
- Decimal numbers
- Power (xʸ)

### 📐 Scientific Functions
- Square Root (√)
- Square (x²)
- Cube (x³)
- Factorial (x!)
- Reciprocal (1/x)
- Absolute Value (abs)
- Random Number Generator
- π (Pi)
- e (Euler's Number)

### 📊 Trigonometric Functions
- sin
- cos
- tan

> Angles are calculated in **degrees**.

### 📈 Logarithmic Functions
- log (Base 10)
- ln (Natural Logarithm)

### 🔄 Number Utilities
- Floor
- Ceil
- Round
- Positive / Negative Toggle (±)

### 💾 Memory
- ANS button to reuse the last calculated result.

### ⌨️ Keyboard Support
- Number keys
- Arithmetic operators
- Enter → Calculate
- Backspace → Delete
- Escape → Clear

### ⚠️ Error Handling
- Math Error detection
- Syntax Error detection
- Division by zero handling
- Invalid input validation

### 📱 Responsive Design
- Fully responsive layout.
- Works on desktop, tablet, and mobile devices.
